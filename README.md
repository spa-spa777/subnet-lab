# Subnet Lab — IPv4サブネット計算 PWA

## 主な機能
- IPv4アドレスとCIDR（/0〜/32）の即時計算
- ネットワークアドレス、マスク、ワイルドカード、ブロードキャスト、ホスト数、アドレス範囲
- 32ビット表示（ネットワーク部／ホスト部の色分け）
- CIDRスライダー、プリセット、結果コピー
- Service Workerによるオフライン対応（初回オンライン読込後）
- /31はRFC 3021に基づくポイントツーポイント用途、/32は単一アドレスとして扱う

## iPhoneへのインストール
1. フォルダ全体をHTTPS対応の静的Webホスティング（GitHub Pages、Netlify等）にアップロード。
2. iPhoneのSafariで公開URLを開く。
3. Safariの共有メニューから「ホーム画面に追加」を選択。
4. 初回表示後はオフラインでも計算可能。

**注意:** ZIPをiPhoneの「ファイル」アプリで開くだけでは、Service Workerやホーム画面へのPWAインストールは機能しません。HTTPS公開が必要です。IPアドレスは外部送信しません。

## 開発用
フォルダで `python3 -m http.server 8000` を実行し、PCのブラウザから `http://localhost:8000` で動作確認できます。
